================================================================================
ENDPOINTS API IMPLEMENTADOS
================================================================================

  GET    /capas              - Listar capas (paginado)
  GET    /capas/{id}         - Obtener capa por ID
  POST   /capas              - Crear capa (201)
  PUT    /capas/{id}         - Actualizar capa (200)
  PATCH  /capas/{id}/estado  - Activar/Desactivar capa (200)

================================================================================
REGLAS DE NEGOCIO IMPLEMENTADAS
================================================================================

  1. Nombre de capa es obligatorio
  2. Nombre no puede repetirse (unique constraint)
  3. Crear capa con nombre duplicado devuelve 409 Conflict
  4. No se elimina fisicamente capas (soft delete via 'activa')
  5. Capa inexistente devuelve 404 Not Found
  6. Permisos: solo rol "Administrador" puede acceder

================================================================================
DATOS INICIALES (SEED)
================================================================================

El seed crea 3 capas si no existen:
  1. Auditor
  2. Supervisor
  3. Gerente

Caracteristicas:
  - Idempotente: no duplica si ya existen
  - Todas quedan activas por defecto
  - Se ejecuta automaticamente al iniciar el servidor
